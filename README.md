# Task2_Modules - система модулей с зависимостями

## Требования
- .NET 9.0 (или 8.0) SDK

## Запуск
1. Перейти в папку проекта:
   cd Task2_Modules
2. Восстановить зависимости:
   dotnet restore
3. Запустить приложение:
   dotnet run

## Конфигурация
Файл `appsettings.json` содержит список модулей для загрузки:
{
  "Modules": [ "Reporting", "Validation", "Export" ]
}

## Проверка ошибок
- Отсутствующий модуль: измените список, добавив несуществующее имя.
- Циклическая зависимость: создайте модули, зависящие друг от друга.
